CSP【決定】: proxy.ts でリクエストごとに nonce を作り、次を基本とする(値の詳細は詳細設計で定める)。

- `script-src 'nonce-…' 'strict-dynamic'`。`strict-dynamic` ではホストの指定が無視されるため、Turnstile のスクリプトにも nonce を付けて読み込む。
- `frame-src` に Turnstile の配信元。`worker-src 'self' blob:`(ZIP を処理する Web Worker のため)。
- `img-src 'self' https://*.4sqi.net`。
- `form-action 'self'` に、Google ログインのリダイレクト先(Supabase Auth のオリジンと Google のログイン画面)を加える(JavaScript の読み込み前にフォーム送信された場合、リダイレクト先も `form-action` の対象になるため)。
- `object-src 'none'`、`base-uri 'none'`、`frame-ancestors 'none'`。
- nonce を使うと全画面が動的に描画され、静的に近い画面もリクエストごとに関数が動く。その分の Netlify の使用量を見込む。

その他のセキュリティヘッダ: HSTS、X-Content-Type-Options、Referrer-Policy、Permissions-Policy。

秘密情報(値はリポジトリに置かない): Supabase の secret key、Turnstile のシークレット、ログイン意図 Cookie の署名鍵とレート制限キーの HMAC 鍵(Next.js 側)、Google OAuth のクライアントシークレットと SMTP の認証情報(Supabase 側)。
