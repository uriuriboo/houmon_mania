# 14. ディレクトリ構成(概要)

> [基本設計書 目次](README.md) ｜ 前: [13. 技術スタック](13_技術スタック.md) ｜ 次: [15. 要件トレーサビリティ](15_トレーサビリティ.md)

---

```text
swarm_search/
├─ doc/                    設計書・調査資料(archive/ に旧版)
├─ src/
│  ├─ app/                 Next.js App Router(画面・Route Handlers・Server Actions)
│  ├─ components/          UI コンポーネント(shadcn/ui を含む)
│  ├─ features/            機能別モジュール(auth / consent / import / search / checkin / account)
│  ├─ workers/             ZIP の展開・検証を行う Web Worker
│  ├─ lib/                 共通処理(Supabase クライアント、エクスポートの形式定義と変換、設定、ログ)
│  └─ proxy.ts             セッション更新・未ログイン時のリダイレクト・CSP
├─ supabase/
│  ├─ config.toml
│  ├─ migrations/          スキーマ・RLS・GRANT・関数・pg_cron の定義
│  ├─ tests/               pgTAP テスト
│  ├─ seed.sql
│  └─ fixtures/            マスク済みのエクスポート
├─ tests/                  E2E テストと補助処理
├─ netlify.toml
├─ .nvmrc
└─ package.json
```

詳細なモジュール構成は詳細設計書で定める。
