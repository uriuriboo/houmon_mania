| D-6 | 長期間使われないアカウント | MVP では自動削除しない(プライバシーポリシーに扱いを書く)。例えば「最終ログインから2年で通知のうえ削除」などの方針を設けるか | 9.5 |

| D-8 | アプリ名・ドメイン・公開時のプラン | 仮称「Ashiato(足あと検索)」。専用ドメインで公開する。公開時は Netlify(Personal + 米国 / Pro + 東京)と Supabase Pro。米国を選ぶ場合は越境移転の扱いも判断材料にする | 1章, 11章 |
