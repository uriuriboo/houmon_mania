# 1. 前提条件・決定済み事項

> [基本設計書 目次](README.md) ｜ 前: [0. 本書の位置づけ](00_本書の位置づけ.md) ｜ 次: [2. システム概要](02_システム概要.md)

---

| 区分 | 内容 | 根拠 |
|---|---|---|
| データ取得 | 利用者がアップロードする Foursquare 公式エクスポートのみ【決定】。Foursquare API は使わない | 2026-10-16 ユーザー決定、報告書 2.1・15章 |
| 利用規約上の位置づけ | エクスポートは利用者本人のデータ(データポータビリティ)で、API のキャッシュ規定は及ばない可能性が高い。ただし店名などは Foursquare の消費者規約上「個人的・非商用」の利用許諾にとどまる。**非商用で、各利用者が自分のデータを検索するためだけに使う**ことを前提とし、商用化する場合は事前に法務確認を行う | 報告書 15.1 |
| ログイン | Supabase Auth の Google ログインと、メールのワンタイムリンク(コードの入力も可)【決定】 | 2026-10-16 ユーザー決定 |
| ホスティング | Netlify(Next.js 公式アダプタ)【決定】。開発中は無料プラン、公開時に有料プランを選ぶ。**関数と DB は同じリージョンに置く**。使う Netlify アカウントがクレジット制かレガシープランかを S-4 の前に確認する | 報告書 11章、2026-10-16 ユーザー決定 |
| UI | タイムライン型【決定】 | 2026-10-16 ユーザー決定 |
| 実行環境 | Node.js 24 LTS(開発機・Netlify 共通)【決定】。Supabase の JS ライブラリなどが Node 22 以上を必須にしたため | 報告書 12章 |
| UI 言語・日時 | UI は日本語のみ。チェックイン日時はチェックインした場所の現地時刻で表示する | |
| 対象ブラウザ | Chrome / Edge / Safari / Firefox の最新版、iOS Safari・Android Chrome(直近2メジャー)。Tailwind CSS v4 の要件(Chrome 111、Safari 16.4、Firefox 128 以上)を下限とする | 報告書 12章 |
| アプリ名・ドメイン | 商標規定により Foursquare / Swarm / 4SQ / Check-in をアプリ名・ドメインに含められない。仮称「Ashiato(足あと検索)」とし、公開前に確定する。非公式アプリである旨と商標の免責文を表示する。アプリは専用のドメイン(またはサブドメイン)で公開し、他のサービスと Cookie を共有しない | 報告書 2.2 |
| 開発機の制約 | Docker が未導入で、WSL2 も起動できない(BIOS で仮想化が無効)。L-01 を満たすには、仮想化の有効化と Docker Desktop の導入が必要 | 2026-10-16 確認 |
