本アプリが外部とやり取りするのは、(1) 利用者が選ぶエクスポートのファイル、(2) Netlify からの静的ファイルの取得、(3) Foursquare の画像 CDN からの写真の取得、の3つだけである。

## 7.1 取り込むエクスポートの形式【暫定 S-1】

Foursquare はエクスポートの形式を公式に文書化していない。以下は2019〜2026年の実例から組み立てた想定で、S-1 で実物を確認して確定する。

| ファイル | 想定 | 使い方 |
|---|---|---|
| `checkins*.json`(`checkins1.json`、`checkins2.json`… または `checkins.json`) | `{"count": N, "items": [チェックインレコード…]}`。1000件ずつ分割 | すべて読み込む。連番の欠番と、各ファイルの件数を確認する |
| `photos*.json`(`photos.json` または `photos1.json`…) | 写真の情報(id, createdAt, prefix, suffix, width, height, visibility, fullUrl, relatedItemUrl) | relatedItemUrl でチェックインに対応付ける |
| その他(users, visits, unconfirmed_visits, comments, tips, lists, venueRatings, paymentProfiles, uniqueDevices, pix/ など) | — | **展開しない・読み込まない** |
| `*.csv` | JSON と同じ内容 | 使わない(JSON を優先) |

チェックインレコードの想定(2024-11 の実例。ID はマスク):

```json
{"id":"673583d9xxxxxxxxxxxx5c32","createdAt":"2024-11-14 05:00:09.000000","type":"checkin",
 "visibility":"closeFriends","entities":[],"shout":"Kareoke time!","timeZoneOffset":-300,
 "venue":{"id":"52854129xxxxxxxxxxxxff56","name":"The Brew Inn","url":"https://foursquare.com/v/..."},
 "comments":{"count":0}}
```

取り込み処理の前提:

- ファイル名は前方一致とワイルドカードで探す(`checkins*.json`、`photos*.json`)。ZIP の中のフォルダ名(`data-export-XXXX/` など)は問わない。ただし、同じ名前のファイルが複数のフォルダにある場合は、複数のエクスポートが混ざっているとみなしてエラーにする。
- 古い形式では `checkins.json` が分割されず1つのファイルに全件が入っていることがあるため、1ファイルの大きさの上限は分割形式と分けて決める(S-5)。
- createdAt は文字列(UTC)と UNIX 秒の整数の両方を受け付ける。
- venue・visibility・shout が無いレコードを許容し、venue の代わりに location を持つレコードや、event を持つレコードも扱う。
- 既知でない形式(想定するファイルが無い、レコードに id や createdAt が無いものが多い)の場合は取り込みを止め、形式が変わった可能性を案内する。

## 7.2 Netlify(静的配信)

| 項目 | 内容 |
|---|---|
| 配信するもの | Next.js の静的書き出し(`out/`)の HTML・JS・CSS・画像・マニフェスト |
| ヘッダ | セキュリティヘッダ(10章)を付ける。Next.js の静的書き出しでは設定ファイルのヘッダ指定が使えないため、内容の変わらないヘッダは `netlify.toml` に書き、CSP はビルドのたびに生成する `out/_headers` に書く(インラインスクリプトのハッシュがビルドごとに変わるため。10.2) |
| サーバー側の処理 | 無し(Functions・Edge Functions を使わない) |
| 送られる情報 | ページの URL のうち `#` より前の部分(検索語は `#` 以降にあるため送られない)、IP アドレス、User-Agent など、通常の Web アクセスの情報 |

## 7.3 Foursquare の画像 CDN

| 項目 | 内容 |
|---|---|
| 用途 | 写真の表示のみ |
| URL | 写真の情報の prefix + サイズ + suffix。許可したパターンに一致するものだけを使う(9.4) |
| 送られる情報 | 画像の URL、IP アドレス、User-Agent。リファラは送らない(`referrerpolicy="no-referrer"`) |
