## 17.1 決定済み(2026-10-16)

| No | 事項 | 決定 |
|---|---|---|
| D-1 | 要件定義書の改訂 | 方式変更に合わせて改訂する。改訂は要件定義書 v2.0 に反映済み(ログインとサーバー保存をやめた差分は本レビューで確認いただく) |
| D-2 | 削除の猶予期間 | 設けない。データは利用者の操作で即時に削除する |
| D-3 | 要件にない追加 | 本書の案のとおり入れる(ホーム画面への追加の案内、削除候補の安全条件の具体値、取り込みの途中終了の検知、画面のスリープ防止、展開済みのフォルダの選択、鮮度の案内、このアプリについて・プライバシーポリシーの画面、件数・大きさの上限の初期値、画面表示の目標)。上限の値は詳細設計で確定する |
| D-4 | AND と OR の混在 | 括弧なしの混在はエラーにする |
| D-5 | 小文字の and / or | エラーにして、大文字での入力か引用符を案内する |
| D-6 | 長期間使われないアカウント | アカウントが無いため不要 |
| D-7 | 市区町村の補完 | 本書の案のとおり。MVP には入れず、S-1 でエクスポートに座標が含まれていると分かった場合に、公開データ(国土地理院など)で市区町村を補い、地名で検索できるようにする拡張を検討する。ブラウザ内で行うため、地名データの配布の大きさも判断材料にする |
| D-9 | オフライン対応 | MVP では対応しない(画面のファイルは毎回取得する)。将来対応する場合は、サービスワーカーで画面のファイルを端末に保存する |
| D-10 | 検索式を URL に持つか | URL の `#` 以降に持つ。戻る/進む・再読み込み・ブックマークで同じ検索を再現できる。検索式がブラウザの閲覧履歴とその同期先に残ることは、プライバシーポリシーとデータの削除の画面で明示する(9.5、16章 R-16) |
| — | データの置き場所 | ブラウザ内で完結する(ログインなし、Supabase なし) |
| D-11 | ホスティング(2026-10-22 追加) | Netlify から **Vercel** に変更する。本書の `netlify.toml`・`out/_headers` の記述は、`vercel.json` と、各 HTML に埋め込む meta の CSP に読み替える(`doc/3_detailed design/00_実装メモ.md` の 2.2) |
