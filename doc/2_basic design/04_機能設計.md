## 4.1 機能一覧

| 機能ID | 機能名 | 概要 | 起動契機 | 対応要件 |
|---|---|---|---|---|
| IMPT-01 | エクスポートの申請案内 | エクスポートの申請手順(Swarm アプリ・Web)と、届くまでの目安を案内する。iPhone・iPad では、先にホーム画面に追加してそこから開くよう案内する | 取り込み画面、データ0件時 | F-16 |
| IMPT-02 | ファイルの読み込みと分析 | 選んだ ZIP(または展開済みのフォルダ・JSON)から `checkins*.json` と `photos*.json` だけを取り出し、検証して、既存データとの差分(新規・更新・変更なし・削除候補)を算出する。この段階では保存しない | 取り込み画面でファイルを選択 | F-10, F-12, N-11, N-12 |
| IMPT-03 | 保存 | 分析結果を確認した利用者の操作で、チェックインと写真の情報を保存する。削除候補は、安全条件を満たし、利用者が反映を選んだ場合だけ削除する。進捗を表示する | 「取り込む」ボタン | F-10, F-11, F-12, F-13 |
| IMPT-04 | 取り込みエラー処理 | 形式の不一致・保存領域の不足などの原因と対処を表示し、やり直せるようにする | 取り込み中のエラー | F-14 |
| SRCH-01 | チェックイン検索 | 検索式を解析・検証し、ブラウザ内で照合する。総件数と表示ページ分のデータを返す | 検索画面での検索・ページ移動 | F-20〜F-26, N-05, N-10 |
| SRCH-02 | 検索結果表示 | タイムライン表示、件数表示、ページネーション、該当なし表示、検索条件の解釈表示 | 検索結果の受信 | F-24, F-30, F-31 |
| DETL-01 | チェックイン詳細 | 保存データ(写真を含む)を表示し、Foursquare 上の店ページへのリンクを示す | 一覧の1件をクリック | F-33 |
| DATA-01 | 保存状況の表示 | 保存件数、最新チェックインの日時、最終取り込み日時、保存領域の状態(永続化の有無、使用量)を表示する | データ管理画面、ヘッダー | F-04, F-17 |
| DATA-02 | 永続化の要求 | 取り込みの完了時に、ブラウザに保存領域の永続化を求め、結果を表示する | 初回の取り込み完了時、データ管理画面 | F-17 |
| DATA-03 | データの削除 | このブラウザに保存したデータをすべて即時に削除する | データ管理画面 | F-03, F-40 |
| APP-01 | 起動時の確認 | 保存データの有無・保存形式の版・前回の取り込みが途中で終わっていないかを確認し、必要なら案内や形式の移行を行う | 画面を開いたとき、bfcache から復帰したとき | F-17, N-06 |
| APP-02 | タブ間の調整 | 同じブラウザの複数のタブで、取り込み・削除・形式の移行が同時に走らないようにし、完了後に他のタブの表示を更新する | 取り込み・削除・移行の開始と完了 | — |
| DEV-01 | ローカル開発環境・テスト用データ | `next dev` での開発、架空データの fixture と疑似エクスポートの生成 | 開発者の操作 | L-01, L-02, L-05 |

## 4.2 処理の流れ

### 4.2.1 起動と検索の準備 — APP-01

```mermaid
sequenceDiagram
  autonumber
  actor U as 利用者
  participant B as 画面
  participant W as 取り込みワーカー
  participant S as 検索ワーカー
  participant D as IndexedDB
  U->>B: 画面を開く(Netlify から静的ファイルを取得)
  B->>D: 状態のストアだけを読む(保存形式の版、件数、取り込みの途中終了の印)
  alt データなし
    B-->>U: 取り込みへ案内(データが消えた可能性と対策も示す)
  else 保存形式が古い
    B->>W: 形式の移行を依頼(排他ロックを取得)
    W->>D: 新しい版で開き直し、raw から値を作り直す
    alt 他のタブが古い版で開いている(開き直しが保留)
      W-->>B: 保留
      B-->>U: 「他のタブを閉じるか再読み込みしてください」
    else 移行完了
      W-->>B: 完了
      B->>S: 検索の準備を依頼
    end
  else 前回の取り込みが途中で終わっている
    B-->>U: 「もう一度読み込んでください」と案内(保存済みの範囲は検索できる)
    B->>S: 検索の準備を依頼
  else 通常
    B->>S: 検索の準備を依頼
  end
  S->>D: 検索用のストア(ID・日時・検索用テキスト)だけを読み込み、メモリに保持
  S-->>B: 準備完了(件数)
```

### 4.2.2 エクスポートの取り込み — IMPT-01〜04

```mermaid
sequenceDiagram
  autonumber
  actor U as 利用者
  participant B as 画面
  participant W as 取り込みワーカー
  participant D as IndexedDB
  participant O as 他のタブ
  U->>B: エクスポートの ZIP(またはフォルダ)を選ぶ
  B->>W: ファイルを渡して分析を依頼
  W->>W: 排他ロックを取得(分析の開始から保存の完了まで保持)
  W->>W: ZIP の目次を読み、checkins*.json と photos*.json だけを展開
  W->>W: 形式とファイルの欠けを検証、レコードを検証して raw を組み立て直し、ID の重複を除去、写真を対応付け
  W->>D: 検索用のストア(ID と内容のハッシュ)だけを読み、差分を算出(保存はしない)
  W-->>B: 分析結果(件数・期間・新規・更新・変更なし・削除候補・安全条件の判定)
  B-->>U: 結果を表示(削除候補は、安全条件を満たす場合だけ「削除も反映する」を選べる)
  U->>B: 「取り込む」
  B->>W: 保存を依頼(画面のスリープを防ぐ)
  W->>D: 「取り込み中」の印を付ける
  loop 一定件数ずつ
    W->>D: チェックイン・写真の情報・検索用のストアを保存(内容が変わったものだけ)
    W-->>B: 進捗
  end
  opt 削除の反映を選んだ
    W->>D: 削除候補とその写真の情報を削除
  end
  W->>D: 取り込み状況を更新し、「取り込み中」の印を外す
  W->>W: 排他ロックを解放
  W-->>B: 完了
  B->>O: 更新を通知(他のタブは検索用データを読み直す)
  B->>B: 初回なら保存領域の永続化を要求(DATA-02)
```

### 4.2.3 検索 — SRCH-01 / SRCH-02

```mermaid
sequenceDiagram
  autonumber
  actor U as 利用者
  participant B as 画面
  participant S as 検索ワーカー
  participant D as IndexedDB
  U->>B: 検索式を入力して検索(URL のハッシュ部分に q・page・size を記録)
  B->>B: 長さ確認、空白・括弧・引用符の正規化、liqe でパース、規則の検証、中間AST に変換
  alt 検索式のエラー
    B-->>U: エラーメッセージ(原因と書き方の例)
  else 正常
    B->>S: 中間AST・件数・ページを渡す
    S->>S: 語を正規化し、メモリ上の検索用テキストと照合(日時の降順)
    S->>D: 表示ページ分のチェックインと写真の情報を取得
    S-->>B: 総件数と該当ページのチェックイン
    B-->>U: タイムラインと「解釈」を表示
  end
```

### 4.2.4 データの削除 — DATA-03

```mermaid
sequenceDiagram
  autonumber
  actor U as 利用者
  participant B as 画面
  participant W as 取り込みワーカー
  participant S as 検索ワーカー
  participant D as IndexedDB
  participant O as 他のタブ
  U->>B: 「このブラウザのデータを削除」を押し、確認ダイアログで確定
  B->>B: 排他ロックを取得(取り込み・移行の実行中なら、終わるまで待つか中止を選ぶ)
  B->>S: 検索用データを捨てて接続を閉じる
  B->>W: 接続を閉じる
  B->>D: データベースを削除
  D-->>O: 接続を閉じるよう通知(versionchange)
  O->>O: 接続を閉じ、メモリ上の検索用データを捨て、「データが削除されました」と表示(自動では開き直さない)
  alt 他のタブが閉じない(削除が保留)
    B-->>U: 「他のタブを閉じてください」
  else 削除完了
    B->>B: 排他ロックを解放
    B-->>U: 完了(取り込みへの案内)
  end
```
