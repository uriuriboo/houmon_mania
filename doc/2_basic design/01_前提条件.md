# 1. 前提条件・決定済み事項

> [基本設計書 目次](README.md) ｜ 前: [0. 本書の位置づけ](00_本書の位置づけ.md) ｜ 次: [2. システム概要](02_システム概要.md)

---

| 区分 | 内容 | 根拠 |
|---|---|---|
| データ取得 | 利用者が読み込む Foursquare 公式エクスポートのみ【決定】。Foursquare API は使わない | 2026-10-16 ユーザー決定、報告書 2.1・15章 |
| データの置き場所 | **利用者のブラウザの中(IndexedDB)だけ**【決定】。取り込んだデータ・検索語・閲覧内容はサーバーに送らない | 2026-10-16 ユーザー決定 |
| ログイン | **設けない**【決定】 | 同上 |
| サーバー | 静的なファイルの配信だけ。サーバー側の処理(関数・DB)は持たない。Supabase は使わない | 同上 |
| 利用規約上の位置づけ | エクスポートは利用者本人のデータ(データポータビリティ)。運営者はデータを預からないため、API のキャッシュ規定の問題は生じない。店名などは Foursquare の消費者規約上「個人的・非商用」の利用許諾であり、**非商用で、各利用者が自分の端末で自分のデータを検索する**ことを前提とする | 報告書 15.1 |
| ホスティング | Netlify(静的サイトとして配信)【決定】。サーバー側の処理が無いため、無料プランで運用できる見込み(本番デプロイの回数に注意。12.4) | 2026-10-16 ユーザー決定 |
| フレームワーク | Next.js を静的書き出し(Static Export)で使う【決定】 | 当初のご指定(Next.js)を維持 |
| UI | タイムライン型【決定】 | 2026-10-16 ユーザー決定 |
| 実行環境 | Node.js 24 LTS(開発・ビルド)【決定】 | 報告書 12章 |
| UI 言語・日時 | UI は日本語のみ。チェックイン日時はチェックインした場所の現地時刻で表示する | |
| 対象ブラウザ | Chrome / Edge / Safari / Firefox の最新版、iOS Safari・Android Chrome(直近2メジャー)。下限は Tailwind CSS v4 の要件(Chrome 111、Safari 16.4、Firefox 128)。IndexedDB・Web Worker・Web Locks・BroadcastChannel が使えること | 報告書 12章、16.1 |
| アプリ名・ドメイン | 商標規定により Foursquare / Swarm / 4SQ / Check-in をアプリ名・ドメインに含められない。「Visit_Mania(足あと検索)」とし、公開前に確定する。非公式アプリである旨と商標の免責文を表示する。保存領域はドメイン(オリジン)ごとに分かれるため、公開後にドメインを変えると利用者のデータは引き継げない(読み込み直しが必要) | 報告書 2.2 |
| 開発機 | Docker と Supabase が不要になったため、開発機の制約(Docker 未導入、WSL2 が起動不可)は影響しない | 2026-10-16 確認 |
