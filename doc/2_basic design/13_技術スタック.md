---

| 領域 | 採用(2026-10-16 時点の版) | 備考 |
|---|---|---|
| ランタイム(開発・ビルド) | Node.js 24 LTS(24.22.0)、npm 10.9 以上 | 利用者の端末では Node.js は動かない |
| フレームワーク | Next.js 16.4.x(16.4.1 以上)、App Router、静的書き出し(`output: 'export'`) | サーバー側の機能(Route Handlers、Server Actions、proxy、画像最適化)は使わない |
| 言語 | TypeScript 6.0.x(strict) | |
| UI | React 19.3、Tailwind CSS 4.3、shadcn/ui(Base UI)、lucide-react 1.x | ダークモードは CSS のみ |
| 入力検証 | zod 4 | エクスポートのレコード、`#` 以降の値の検証 |
| 検索式パース | liqe 3.8.7(固定) | ブラウザで動作 |
| ZIP の展開 | 必要なファイルだけを取り出せる ZIP ライブラリ(ワーカーで使用) | 条件(部分読み込み、ZIP64、ストリームでの展開と上限の判定、内部で Blob URL のワーカーを作らない)は 9.2.2。候補の比較と版は詳細設計で決める |
| 保存 | IndexedDB と薄いラッパーライブラリ | 候補の比較と版は詳細設計で決める |
| 並行処理 | Web Worker、Web Locks、BroadcastChannel(ブラウザ標準) | |
| Lint | ESLint 10 + eslint-config-next(flat config) | |
| テスト | Vitest 5、IndexedDB の模擬実装、Testing Library、Playwright 1.64 | |
| ホスティング | Netlify(静的配信) | Functions は使わない |

使わないもの: Supabase(認証・DB)、Foursquare API、解析・広告・エラー収集のサービス、Web フォント、外部 CDN から読み込むスクリプト。

補足: サーバー側の処理を持たないため、Next.js の主な利点(サーバー描画・API)は使わない。当初のご指定に合わせて Next.js を採用するが、Vite + React のような静的サイト向けの構成でも同じものが作れる。
