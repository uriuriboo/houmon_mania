# 11. 非機能設計

> [基本設計書 目次](README.md) ｜ 前: [10. セキュリティ設計](10_セキュリティ設計.md) ｜ 次: [12. 開発・運用環境設計](12_開発・運用環境.md)

---

| 項目 | 目標・方式 | 要件 |
|---|---|---|
| 検索の応答 | 一般的なスマホで、5万件の検索(総件数を含む)が 300ms 以内。PC では20万件でも同程度(S-6 で計測) | N-05 |
| 検索の準備 | 画面を開いてから検索できるまで、5万件で3秒以内(S-6 で計測) | N-05 |
| 取り込み | 1万件を PC で30秒以内、スマホで1分以内(S-5 で計測)。取り込み中も画面は操作できる。スマホでは、取り込み中に他のアプリに切り替えると中断することがある(9.2.1) | N-12 |
| 画面表示 | 主要画面の初期表示 2秒以内(モバイル回線相当)【提案】。静的ファイルを CDN から配信する | — |
| 保存できる件数 | 1ブラウザあたり20万件まで(上限値。端末の性能によっては、実際に快適に使える件数が下がる) | N-12 |
| 保存領域 | 5万件で約 30〜60MB、20万件で約 120〜240MB(6.4)。ブラウザの保存領域の範囲内に収まる見込み(S-7 で確認) | — |
| 可用性 | 静的ファイルの CDN 配信。サーバー側の処理が無いため、配信が止まらない限り使える | — |
| データの保全 | データは利用者の端末にある。バックアップは元のエクスポート(ZIP)で、消えても読み込み直せば戻る(9.1.2) | N-06 |
| エクスポートの形式変更 | 形式の判定と変換を1か所にまとめ、raw を保存する。未知の項目名を警告として表示する | N-06 |
| 個人情報 | 運営者は個人情報を受け取らない。プライバシーポリシーに 9.5 の事項を書く | N-11 |
| 費用 | Netlify の静的配信のみ。サーバー側の処理が無いため、無料プランで運用できる見込み(12.4) | — |
| 保守性 | TypeScript による型安全、エクスポートの形式と検索の単体テスト、E2E テスト。依存関係の自動更新 | — |
| アクセシビリティ | WCAG 2.2 AA 相当 | — |
| オフライン | MVP ではオフラインでの起動は対象外とする(画面のファイルは毎回 CDN から取得する。17章 D-9 で決定) | — |
