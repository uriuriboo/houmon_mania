# 14. ディレクトリ構成(概要)

> [基本設計書 目次](README.md) ｜ 前: [13. 技術スタック](13_技術スタック.md) ｜ 次: [15. 要件トレーサビリティ](15_トレーサビリティ.md)

---

```text
houmon_mania/
├─ doc/                    設計書・調査資料(archive/ に旧版)
├─ src/
│  ├─ app/                 画面(すべて静的に書き出すページ)
│  ├─ components/          UI コンポーネント(shadcn/ui を含む)
│  ├─ features/            機能別モジュール(import / search / checkin / data)
│  ├─ workers/             取り込みワーカー・検索ワーカー
│  └─ lib/                 共通処理(エクスポートの形式定義と変換、検索式の解析と照合、正規化、保存、日時表示)
├─ public/                 マニフェスト、アイコン
├─ scripts/                ビルド後の CSP 生成(out/_headers)、疑似エクスポートの生成
├─ tests/
│  ├─ fixtures/            架空データのエクスポート(実物の ZIP・JSON は置かない)
│  └─ e2e/                 E2E テスト
├─ netlify.toml            配信設定・内容の変わらないセキュリティヘッダ(CSP は書かない)
├─ .gitignore              *.zip、実データ用のフォルダ、out/
├─ .nvmrc
└─ package.json
```

`supabase/`(マイグレーションなど)は不要になった。詳細なモジュール構成は詳細設計書で定める。
