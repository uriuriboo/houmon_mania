# 16. リスクと対応

> [基本設計書 目次](README.md) ｜ 前: [15. 要件トレーサビリティ](15_トレーサビリティ.md) ｜ 次: [17. レビューで判断いただきたい事項](17_判断事項.md)

---

| No | リスク | 影響 | 対応 |
|---|---|---|---|
| R-1 | エクスポートの実際の形式が想定と違う(2026年版は未確認) | 取り込みができない・項目が欠ける | S-1 で実物を確認してから詳細設計の取り込み仕様を確定する。形式の判定と変換を1か所にまとめる |
| R-2 | エクスポートの形式が予告なく変わる | 新しいエクスポートを取り込めない | 形式エラーと未知の項目名を検知して表示し、改修する。raw を保存する |
| R-3 | Foursquare がエクスポート機能を変更・停止する | 新しいデータを取り込めない | 取り込み済みのデータの検索は続けられる。公式は継続を表明している |
| R-4 | 検索できる項目が店名・コメントに限られ、期待と違う | 利用者の満足度が下がる | トップ・ヘルプ・該当なし画面で「できること・できないこと」を明示する。座標が含まれていれば、市区町村を補う拡張を検討する(17章 D-7) |
| R-5 | 自動更新が無く、データが古くなる | 最近のチェックインが検索できない | 鮮度の表示と再申請の案内(9.2.7) |
| R-6 | ブラウザが保存データを消す(Safari の7日ルール、容量不足、利用者によるサイトデータの削除) | 検索できなくなる | 永続化の要求、ホーム画面への追加の案内、消えた場合の再取り込みの案内(9.1.2)。S-7 で実機確認 |
| R-6a | iPhone・iPad で、Safari で取り込んだ後にホーム画面に追加すると、ホーム画面のアプリからはデータが見えない(保存領域が別) | 取り込み直しの手間、データが消えたと誤解される | トップと取り込み画面で、取り込みの**前に**ホーム画面に追加し、アイコンから開いて取り込むよう案内する(9.1.2)。S-7 で実機確認 |
| R-7 | データが端末ごとに別 | PC とスマホで別々に取り込む手間 | 画面で明示する。端末間の同期は MVP の対象外 |
| R-8 | 同じ端末・ブラウザを使う他人に見られる | プライバシー | 共有端末で使わないよう案内し、即時に削除できるようにする。パスコードによるロックは将来検討 |
| R-9 | スマホで大量のデータを扱うと遅い・メモリが足りない | 取り込みや検索に失敗する | 必要なファイルだけを展開し、ワーカーで処理し、検索用データだけをメモリに持つ。S-5・S-6 で計測し、必要なら端末ごとの上限を下げる |
| R-10 | 再取り込みの誤操作で、必要なデータを削除してしまう | データの消失 | 削除候補の安全条件と、既定オフの確認(9.2.4)。エクスポートを読み込み直せば戻る |
| R-11 | スクリプトの混入によるデータの持ち出し | 位置履歴の流出 | 混入させないことを主対策とする(テキストとしての表示、URL の組み立て、第三者スクリプトの不使用)。CSP(画面とワーカーの両方)による通信先の制限は補助で、画面の遷移などの経路は残る(10章) |
| R-12 | 依存パッケージの改ざん | 同上 | 依存の最小化、版の固定、更新の確認。CSP は補助(10章) |
| R-12a | GitHub・Netlify のアカウントの乗っ取りによる、改ざんした画面の配信 | 同上(全利用者に影響) | 2段階認証の必須化、main ブランチの保護、Snippet injection の不使用、デプロイの通知(10.1、12.4) |
| R-13 | 規約の解釈(店名などは個人的・非商用の利用許諾) | 商用化した場合に問題になりうる | 非商用を前提とし、商用化する前に法務確認を行う。運営者はデータを預からない |
| R-14 | 公開後にドメインを変える | 利用者の保存データが引き継げない | 公開前にドメインを確定する(17章 D-8) |
| R-15 | スマホで、取り込み中に他のアプリに切り替える・画面がロックされる | 取り込みが中断される | 画面のスリープを防ぎ、画面を開いたままにするよう案内する。中断を検知して読み込み直しを案内する(9.2.1、9.2.5) |
| R-16 | 検索式を含む URL が閲覧履歴とその同期先に残る | 共有の端末や同期先から検索語が分かる | プライバシーポリシーと削除の画面で明示する。検索ボックスの自動補完を無効にする。URL に持つことは17章 D-10 で決定 |
